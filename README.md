# Switch, Switch2の互換用関数
## 機能
### Switch, Switch2両方のSwitchメニュー画面上の動作をサポートする関数です。
* **ソフトの起動・再起動**
* **日付変更（Switch2国内版想定）**
* **本体の再起動（Switchのみ動作）**

Switchの世代およびテーマカラーを判別して動作します。
## アップデート
2026/03/10 ver.1.0.0 リリース
